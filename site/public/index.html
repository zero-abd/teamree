Run your agents
like a team.

Each agent in its own git worktree. One window says which one needs you.

Download for macOSSource on GitHub

Free. macOS 12 or later. Universal build.

A worktree per task

Start from any ref. Attempts never see each other's files; abandoning one is deleting a directory.

A state per pane

Working, waiting, finished or failed, read off the PTY. One view lists every pane, failures first.

  • working
  • waiting
  • finished
  • failed

Split terminals, nested, a real PTY in each. Finds claude, codex, gemini, opencode and droid on your PATH.

A CLI agents can drive

Create worktrees, run commands and read output over a local socket. Every command takes --json.

teamree worktree create --project app --name "fix login"
teamree worktree wait fix-login
teamree terminal run --worktree fix-login --command "npm test"
teamree worktree changes fix-login

Teammates in the window

Add a teammate's key and they can watch your panes and ask to type; keystrokes run only when you allow them.

shasum -a 256 teamree-mac-universal.dmg
