// 10 — install

TEAMREE 00:00:00:00

Installed in a minute.

The build isn't signed with an Apple Developer ID yet, so macOS asks once. Nothing was found wrong with it; it just has no certificate naming who built it.

  1. Download.

    teamree-mac-universal.dmg runs on Apple Silicon and Intel.

  2. Drag teamree to Applications.

  3. Open it, then press Done.

    macOS says “teamree” Not Opened. Press Done, not Move to Trash.

  4. Open Anyway, once.

    System Settings → Privacy & Security → Open Anyway. Or in Terminal:

    xattr -dr com.apple.quarantine /Applications/teamree.app

    It won't ask again.

  5. Add a repository. Press ⌘N.

    Describe a task and pick your agents.

// 11 — faq

TEAMREE 00:00:00:00

Questions, answered.

Is it free?

Yes. Open source under the MIT licence, and the source is on GitHub.

What is an ADE?

An agentic development environment: one window that runs and watches your coding agents, each in its own git worktree, and lands their work. Your editor stays your editor.

Which agents does it run?

Claude Code, Codex, Gemini CLI, OpenCode, droid and the other agent CLIs on your PATH: 21 in all.

Why does macOS warn me?

The build is signed ad-hoc, not with an Apple Developer ID. Press Done, then Open Anyway once. To be sure the file is the one the release built, compare its SHA-256 with the release's SHA256SUMS.txt.

Do teammates need a server?

A relay your team hosts. One command deploys it to your own Cloudflare account; nobody hosts one for you. Trying teamwork

Can the relay read our work?

No. Teammates encrypt end to end; the relay only passes the bytes along.

Can a teammate type in my terminal?

Only after you allow it: once, for the session, or always.

Windows or Linux?

macOS only, by decision.

How does it update?

It checks GitHub releases, downloads a new one in the background and offers Restart to Update.
