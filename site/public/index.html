Parallel coding agents, one window.

A git worktree per task, with its own terminals. Teammates watch, and type when allowed.

Download for macOS Source on GitHub

  • One worktree per task

    Start from any ref. Attempts never see each other’s files; abandoning one is deleting a directory.

  • Split terminals

    Nested, resizable panes, a real PTY in each. Finds claude, codex, gemini, opencode and droid on your PATH.

  • A CLI agents can drive

    Create worktrees, run commands and read output over a local socket. Every command takes --json.

  • Status per pane

    Working, waiting, finished or failed, read off the PTY. One view lists every pane, failures first.

Teamwork

Add a teammate’s key and they can watch your panes and ask to type; keystrokes run only when you allow them. Trying teamwork is the walkthrough.

Install

Free, macOS 12 or later, signed ad-hoc. macOS refuses the first launch: press Done, not Move to Trash, then clear the flag.

xattr -dr com.apple.quarantine /Applications/teamree.app

Check the download against SHA256SUMS.txt on the release page.

shasum -a 256 teamree-mac-universal.dmg

Why macOS asks, and what it does not mean: docs/install.md.
