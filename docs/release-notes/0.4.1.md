The sidebar shows only the subagents still running.

- Subagents a Claude pane starts appear under its row while they run and disappear when they finish; click one for its transcript.
- New Task has a Branch field: named from the task, editable, and checked before you start.
- New Task asks each agent's permission mode: Default, Auto or Bypass.
- Hover an `[Image #N]` in a Claude pane to preview the pasted image; click to open it.
