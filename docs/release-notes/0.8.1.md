⌘A selects what you typed, and change counts agree everywhere.

- ⌘A in a terminal selects only what you've typed at the shell prompt or in an agent's input box, so Backspace clears it; press again for everything.
- Change counts agree everywhere: a partly staged file counts once, a new folder counts its files, and status reads are faster.
- Discard on a hunk shows the lines it throws away.
- The commit box clears after Clear Lock.
- A batched review comment is marked on its line.
- Search focuses its field and keeps the result you clicked.
- A click in front matter lands on the value.
- Right-click on a terminal path always offers Open File.
