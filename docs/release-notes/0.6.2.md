Safer relaunches, handoffs that carry the work, and joining from a link.

- Relaunching never re-sends a task to an agent; a pane whose conversation is gone comes back stopped, with Resume Conversation… and Start Fresh.
- A question an agent asks you counts as needing you everywhere, and a timed-out one offers Send Anyway.
- Hand Off commits your uncommitted work, stops your agent and gives your teammate's agent a brief.
- Join a Team… from the welcome screen, the File menu or the palette; invitations are now links to teamree.us/join.
- The status bar says when origin can't be reached or the last fetch is old, with Fetch Now.
- A stale git lock offers Retry and Clear Lock…; splits stay even and tabs keep their names.
- Compact rows keep task names readable and fold extra chips into +N.
