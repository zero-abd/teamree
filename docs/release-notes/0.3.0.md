## What changed since 0.1.2

0.2.0 was never published, so this covers everything since 0.1.2.

### Updates install themselves

teamree checks for a new release on launch, hourly and on wake, and downloads
it in the background. The download is refused unless its size, SHA-256 and
signature check out. When it is ready, a card offers **Later** and **Restart to
Update**: teamree quits as Quit does, swaps the app in place and reopens. If the
new copy will not open, the old one comes back. **Help › Check for Updates…**
checks now; Settings › Updates turns automatic checks off.

On 0.1.2, install this build by hand once. Later releases arrive this way.

### The sidebar says who needs you

- One dot per worktree. Amber only when an agent is asking; violet while it works.
- An asking row shows the question, with its answers as buttons (Trust, Yes,
  Run…). Answer without opening the pane.
- **⌃⌘↓** / **⌃⌘↑** go to the next pane that needs you, across every worktree.
- Each worktree is drawn as its own box.

### Review

- **Review All** (**⌘⇧R**) opens every change as one tab: the task, the agent's
  last line, then each file with a Viewed box. j/k step file to file.
- **+** in a diff gutter comments on a line or range. **Send to Claude Code**
  types it into the agent's pane; **Add to Batch** sends several as one message.
- Commits in Changes open as read-only tabs.
- Start one task with several agents, **Compare with** to see two runs side by
  side, and **Keep This Run** to keep one and remove the rest.

### Landing

- **Create Pull Request** once the branch is published (through gh, else the
  host's compare page). A repository on no known host gets **Merge into main**.
- Main is fetched in the background. Changes shows ↓1 and **Update from main**
  rebases or merges; a conflict goes to the agent to resolve, or Abort. Off per
  project in Settings › Projects › Fetch in Background.

### Nothing lost for good

- Remove and Discard save a copy first. **Undo** for ten seconds; older ones
  under **Recently Removed** on the project's menu, kept 14 days.
- Right-click a project or worktree: **Remove from teamree** keeps the folder,
  **Move to Trash…** trashes it.
- **⌘⇧T** reopens a closed pane. An agent resumes its session.

### Teams

- **Copy Invitation** is one `teamree://` link. Opening it clones, adds the
  project and joins.
- **Open Branch…** and **Open Pull Request…** open a teammate's work as a
  worktree, optionally with a reviewer agent.
- `.teamree/project.json` shares the setup command, linked and copied paths and
  start point. A setup command from the repository runs only after **Run**; each
  Mac approves each command once.
- A teammate's keystrokes in your pane wait for you: allow once, for this
  session, or always. Mute still wins. `teamree team requests`, `team allow` and
  `team deny` answer from the command line.
- A teammate's pane is an ordinary pane beside yours. Several can be open.
- Team setup shows each step's progress. A push that hung on an ssh prompt now
  fails with the command that fixes it.

### Also

- Markdown pages beside the panes: block handles, a / menu, drag to reorder.
- Settings has sections and a filter. Appearance lives there (**⌘,**): Light,
  Dark or Match System, presets, every colour editable.
- **Trust New Worktrees** (Settings › Agents): a new worktree is trusted by
  claude and codex when its main checkout already is.
- **⌘P** goes to a file, **⌘K** runs any command, **⌘F** finds in a diff. Stage
  or discard a single hunk.
