Review, merge and nest tasks more easily.

- Review a whole branch against its base, even after everything is committed; the merge dialog has Review too.
- A child task merges into its parent, shows how far behind its parent it is, and has Update from Parent.
- Drag a task onto another to nest it, or use Move Under… in the row menu.
- Images pasted into Claude Code show as thumbnails under the pane, with − to minimize.
- Settings › Notifications has Send Test.
