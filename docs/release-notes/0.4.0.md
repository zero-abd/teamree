Task trees, shared notes and a menu bar icon.

- Split a task into child tasks that branch from it and nest under it in the sidebar: New Child Task… (⌘⇧N).
- All Panes has a Tasks view with each task's stage.
- Share a note with your team; teammates get View or Close.
- Teammates see each other's tasks and changed files. Settings › Teamwork turns it off.
- teamree lives in the menu bar: who's asking, New Task and Quick Note.
- Agents see what sibling tasks touch with `teamree context`, `claim` and `note`, and every pane has the `teamree` CLI.
- Updates are signed; teamree installs only releases signed by its maintainer.
