Hand work to teammates, run your dev server, and see what each task costs.

- Hand Off… a task to a teammate: they get Take, which opens the branch and starts their agent with your note.
- A teammate's asking agent shows as asking, with answer buttons that go through their consent.
- Shared notes are kept in a list on the Teamwork page, which now names its project; joining a team no longer needs a `git pull`.
- ▶ Dev and ▶ Tests run the project's commands in named panes; dev server ports show on the row, and Show Ports lists them all.
- Tokens per task on the board, with an optional cost estimate in Settings.
- Claims and decisions show in the Changes panel, and Show Decisions lists them for the whole project.
- Settings: where worktrees go, a branch prefix, and a search box.
- Fixes: panes closed quickly no longer leave empty panes, narrow windows never refuse a pane, and the safety copy before Remove catches every edit.
