Agents can outlive teamree, a new look, and a home for the team.

- Agents can keep running when teamree quits or crashes (Settings › Panes, experimental, off by default).
- A new look: Charcoal dark theme with stepped surfaces, flush panes, larger type, one icon set, and worktree rows that show branch and base.
- The team at a glance: faces, presence, asking and handoff cues, plus a Teamwork home with members, waiting on you, notes and activity.
- Settings adds Git, Keep Awake, default editor, fetch interval, shell, line height, per-event notifications and shortcuts, and sits at the bottom of the sidebar.
- Back/Forward between worktrees, ⌘K opens on recent worktrees and running panes, and Quick Note ⌘⌥N.
- Terminal: Mac editing keys (⇧↩ for a newline in agents), correct emoji widths, and Clear Pane ⌥⌘K.
- Files: tabs stay in view, preview tabs, go to file:line and ⌃G, markdown front matter and a Source view.
- Errors are logged instead of shown in a raw dialog (Help › Show Error Log); optional Jac Graph Memory add-on in Settings › Add-ons.
