A new worktree's setup runs to the end before its agent starts.

- Setup runs as its own pane and the agent starts only once it passes; a passed setup closes itself.
- A failed setup holds the agent and offers Run Again, Start Agent Anyway and Open Shell.
- Hover any small icon, count, dot or pill for what it means, e.g. "48 commits behind origin/master".
- Sidebar pane rows say their agent and state, a setup's command or exit code, and a cut-off line in full.
- A `teamree msg ask` question shows in its pane and in All Panes with its answers; Escape in Reply returns to the answers.
- "Start new worktrees from" is saved on the project and used by the CLI too; an unknown ref is refused.
- `teamree worktree create --agent` waits for setup to pass before starting the agent.
