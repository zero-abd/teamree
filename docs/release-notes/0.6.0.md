Conflicts have a way through, landing reaches origin, and big setups stay fast.

- Merge conflicts show in the Changes panel with Take Ours, Take Theirs, Mark Resolved and Continue; Ask Agent to Resolve is always there.
- Sibling tasks turn red when their changes would conflict, even before either commits.
- Merge into main can push to origin, and New Task starts from local main when it is ahead.
- Pull requests show their checks and review on the row; Send Failure to Agent pastes a failing check's log.
- Commit messages start from the agent's done report.
- A file save re-reads git only in that task, so 150 worktrees stay quiet.
- Sidebar filter and Compact view; big diffs open readable with Show Full Diff; search results show the match.
- Screen readers hear each row in one sentence, and a deleted checkout says Checkout missing, with Restore.
