Agents coordinate, and more is in plain sight.

- Agents ask, reply and report done to each other and to you with `teamree msg`; an ask to you shows on the row with answer buttons.
- Overlap chips show when sibling tasks change the same file, red when they would conflict.
- Start a task from a GitHub issue; its pull request closes the issue.
- Resume any past Claude Code or Codex conversation in a worktree.
- Clean Up Merged… removes finished worktrees in one go, with one Undo.
- Diffs highlight changed words, with Wrap and Hide Whitespace.
- Controls show without hovering, merging is always one click away, and the palette offers New Task when nothing matches.
- New worktrees suggest a setup command, × removes a pasted image from the prompt, and quitting is faster.
