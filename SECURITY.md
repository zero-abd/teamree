# Security

## Reporting

Report vulnerabilities privately through the repository's
[Report a vulnerability](https://github.com/zero-abd/teamree/security/advisories/new)
form. Do not open a public issue.

## Scope

- The updater: release lookup, download, bundle check and the install helper (`src/main/updates/`)
- The runtime socket the CLI and agents talk to
- P2P teamwork: pairing, the relay, and what a teammate can see or drive
- The repository setup command from `.teamree/project.json` and its approval

## Supported versions

Only the latest release gets fixes.
